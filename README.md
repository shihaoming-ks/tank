# 🎮 AI 坦克竞技场（Tank Arena）

服务端权威的在线多人坦克对战游戏。浏览器直接进入，2～4 名玩家同房间对战，
所有关键战斗结果（生命值、淘汰、胜负）由服务端统一裁决，保证多端一致。

> **当前状态**：MVP 开发中。视觉元素由 Canvas 几何图形占位，暂未接入美术素材。

---

## 快速开始

环境要求：**Node.js ≥ 18**（推荐 22，见 `.nvmrc`）

```bash
# 安装依赖（快手内网需加 --registry https://npm.corp.kuaishou.com/）
npm install

# 启动（一条命令同时提供页面与 WebSocket 服务）
npm run dev
```

浏览器打开 **http://localhost:8080**

多人测试：**再开一个浏览器窗口**（或无痕窗口）访问同一地址，输入相同房间号即可加入同一局。

> 详细环境说明、环境变量、常见问题排查见 **[docs/SETUP.md](docs/SETUP.md)**

## 游戏规则

- 每名玩家初始 **3 点生命值**，被子弹命中扣 1 点
- 子弹**不会伤害发射者**
- 生命值归零后淘汰；复活时有 **2 秒无敌**
- 对局结束条件（满足任一）：
  1. 仅剩 1 名存活玩家 → 该玩家胜
  2. 时限 **3 分钟**到 → 剩余生命值高者胜，相同则平局
  3. 房间内玩家不足 2 人 → 本局中止

## 技术架构

```
浏览器 A ──┐                  ┌─ RoomManager（房间集合）
           ├── WebSocket ─────┤
浏览器 B ──┘                  └─ Room：30Hz tick → 权威裁决 → 广播快照
```

**服务端权威模型**：客户端只上报操作意图（`input` / `fire`），
服务端计算世界状态并广播结果。客户端不做任何规则判定，仅负责渲染。

| 层 | 技术 | 说明 |
|---|---|---|
| 客户端 | 原生 ESM + Canvas 2D | 零构建，无框架 |
| 通信 | WebSocket（`ws`） | 与页面同源，无跨域问题 |
| 服务端 | Node.js | 单进程，内存态世界状态 |
| 共享层 | `shared/` | 浏览器与 Node import **同一物理文件** |

> 目录结构与分层规则详见 **[docs/STRUCTURE.md](docs/STRUCTURE.md)**

## 可调参数

全部集中在 **`shared/constants.js`**（唯一来源，禁止散落魔法数字）：

| 参数 | 默认值 |
|---|---|
| 地图尺寸 | 30 × 20 格（每格 32px，共 960×640） |
| tick 频率 | 30 Hz |
| 坦克速度 | 120 px/s |
| 子弹速度 | 360 px/s |
| 射击冷却 | 300 ms |
| 初始生命值 | 3 |
| 复活无敌 | 2 s |
| 对局时限 | 180 s |
| 房间容量 | 2 ～ 4 人 |
