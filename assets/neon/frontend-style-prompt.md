# Tank Arena：霓虹未来前端风格实施提示词

为原生 ESM、HTML、CSS 与 Canvas 2D 的 Tank Arena 实现 `neon` 主题。仅修改 `client/styles/main.css`、主题选择相关前端代码与 `assets/neon/`；不得改变服务端、规则或协议。

- 视觉方向：近黑指挥甲板和受控能量网格。主色 `#05050c`，青色 `#3ff7d4`，洋红 `#ff5dc8`，浅文字 `#e8edff`；避免大面积炫光、紫色渐变和拟物圆角。
- 字体与可读性：数值、计时与战报时间使用等宽字；弱文本不低于 `#b8bde3`。状态不能只靠发光或颜色，淘汰、禁用、焦点必须有边框、文本或去饱和差异。
- 组件：使用切角、细框、扫描线和局部青/洋红光；按钮悬停仅上移 1px 并扫过高光，焦点为洋红外描边；Canvas 为青色数据框，HUD 自己的卡片带青色左轨。
- 素材映射：四种坦克为 `tank-*.png`，图块为 `tile-*.png`，特效 `fx-*.png` 为 4 帧横向表，生命格为 `ui-hp-pip-*.png`。加载失败保留 Canvas 几何绘制。
- 动效：光效短促且克制；`prefers-reduced-motion` 下取消扫描和位移，同时保留可见的状态结果。
