# Asset Manifest — Tank Arena / Industrial

## 风格摘要
- **方向：** 克制的工业军械终端；深橄榄黑、旧军用钢板、硬边几何轮廓、轻微磨损、压纹与铆钉。
- **视角与光源：** 严格正俯视；右上方偏冷高光；短、克制阴影。
- **调色板：** 地面 `#12150f`、边界钢 `#5a5f52`、结构砖 `#8a5a3c`、内部钢 `#4a5560`、红 `#e94f37`、蓝 `#3f88c5`、青绿 `#44bba4`、黄 `#f6ae2d`、弹芯 `#ffe9b0`。
- **禁止项：** 文本、数字、Logo、水印、人物、真实战场、浓烟、厚雾、背景承载物。

## 接入与回退
- 图片加载失败时，保留 Canvas 几何绘制：坦克用履带/炮塔形状，墙体用色块与裂缝线，HUD 用短条，特效用线条、粒子和圆环。
- 效果表均以固定中心锚点切片；不要拉伸单帧。

## 生成摘要与验收
- 坦克共享同一正俯视结构；颜色仅作主漆替换。
- 可破坏墙体共享基底，耐久从无裂纹 → 半 X → 完整 X 逐级变化。
- 除淘汰爆炸外，所有特效都改为无场景承载物的透明效果素材。
- 静态素材保留源级细节并裁掉外部空白；无缝图块、UI 框与特效表保留必要画布和锚点。
