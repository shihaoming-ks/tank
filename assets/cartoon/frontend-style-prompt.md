# Tank Arena：卡通手绘前端风格实施提示词

为原生 ESM、HTML、CSS 与 Canvas 2D 的 Tank Arena 实现 `cartoon` 主题。仅修改 `client/styles/main.css`、主题选择相关前端代码与 `assets/cartoon/`；不得改变服务端、规则或协议。

- 视觉方向：野战笔记与桌游插画。使用暖米色纸张、丛林绿不规则墨线、陶土红和浅奶油高光；避免玻璃拟态、冷色霓虹、纯圆润玩具 UI。
- 令牌：正文 `#273b35`、弱文本至少 `#466055`、主强调 `#a53f20`、行动绿 `#2d755f`。输入、快捷键和 HUD 的文字必须在浅色背景保持可读，禁用态仍有边框与清晰文字。
- 组件：面板采用不规则圆角、虚线、轻微旋转和纸胶带；按钮为按压纸片效果，焦点采用 3px 陶土色描边；Canvas 用深绿手绘边框与纸面阴影。淘汰态以文字与去饱和共同表达。
- 素材映射：四种坦克为 `tank-*.png`，图块为 `tile-*.png`，特效 `fx-*.png` 为 4 帧横向表，生命格为 `ui-hp-pip-*.png`。加载失败保留 Canvas 几何绘制。
- 动效：只提供短促按压与小幅纸片位移；`prefers-reduced-motion` 下关闭过渡与位移，不影响焦点和状态区分。
