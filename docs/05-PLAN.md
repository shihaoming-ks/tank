## 已实现能力边界

- 新进入正在对战的房间会成为观战者；观战者出现在房间和结算信息中，但不参与胜负和槽位占用。
- 自动重连依赖浏览器本地 `resumeToken`，仅恢复 20 秒宽限期内的同一玩家。没有账号、跨设备恢复、状态历史或复杂断线续玩。
- 音效采用 Web Audio 合成，没有音频素材包；命中会区分坦克、砖墙、钢墙/边界和撞击，远处无关事件被静音。

## 后续优先级（S6）

1. 真机双人/多浏览器回归：主题切换、观战、断线恢复、道具与音效混战场景。
2. 触控或手柄控制，以及小屏布局专项设计。
3. 多张地图、地图投票或更丰富的战场机制。
4. 账号/长期战绩前，先明确服务端持久化与多实例房间路由方案。
5. 对目标 Linux 机器实际构建、解包、启动、健康检查和局域网联机验收。

## 验收门槛

每项新功能至少满足：

- 不把规则判定移到客户端；关键变化由服务端快照或事件驱动。
- 资源加载失败时游戏仍可玩，且 UI 文本对比度在四主题下可读。
- 补充或更新相应 `node:test` / 冒烟用例；提交前运行 `npm test`。
- 若变动影响部署或资源契约，同步更新 README、运行手册、结构文档与主题清单。
