# 小游戏视觉素材工坊

创建可直接接入项目的栅格视觉素材。生成或编辑位图时优先使用图像生成工具。

## 输入

先收集或作保守推断；只在缺失项会明显改变交付结果时追问。

| 字段 | 内容 |
|---|---|
| `assets` | 所需资产、数量、状态/帧变体与优先级 |
| `style` | 美术方向、时代/题材、视角、光源、轮廓语言 |
| `anchors` | 参考图、调色板、必须保留元素、禁止元素 |
| `technical` | 格式、尺寸、透明度、图块尺寸、帧数与帧排列 |
| `delivery` | 输出目录、命名规则、最大文件大小、缩放方式 |
| `integration`（可选） | 用户提供的项目资产规格、渲染器映射或回退方案 |

将整理后的需求写成简短的素材简报，再开始生成。详细字段见 [references/asset-spec.md](references/asset-spec.md)。

## 工作流

1. 读取用户提供的资产规格；未提供时检查项目现有素材目录、渲染器和命名约定。
2. 建立素材清单：文件名、用途、尺寸、透明度、状态、优先级与生成提示词锚点。
3. 先生成一张能代表风格的关键素材，确认构图、配色、轮廓和视角后，再批量生成同组资产。
4. 对每个生成批次复用相同的风格锚点；只在状态、姿态或对象上改变必要部分。
5. 检查尺寸、Alpha、命名、文件大小、帧布局及目标显示尺寸下的可辨识性；必要时迭代。
6. 不覆盖既有美术文件，除非用户明确授权；将最终资产和素材清单写入指定目录。
7. 提供交付报告，说明文件、接入映射、生成摘要和未解决问题。

## 制作约束

- 优先保证轮廓和玩法信息可读，再添加表面细节。
- 精灵保留安全内边距；不得裁掉炮管、阴影、发光或爆炸边缘。
- 精灵、特效、图标和叠层默认使用透明 PNG；无缝图块必须能四边拼接。
- 动画帧保持画布尺寸、锚点、视角和视觉重心一致；只制作真实玩法状态需要的变体。
- 默认使用小写 kebab-case；命名与状态编码规则见 [references/asset-spec.md](references/asset-spec.md)。
- 不把某个项目的固定尺寸写死为通用规则；项目规格应作为本次输入的 `integration` 约束。

## 验收与交付

逐项检查：

- 每个清单条目都有文件，文件名、格式、像素尺寸和透明度符合简报。
- 同组素材的视角、色温、描边和光源一致；在实际显示倍率下可区分关键状态。
- 精灵表帧数和排列方向正确；图块无明显接缝；透明素材无意外底色。
- 资产能被渲染器映射；若项目要求加载失败回退，则该回退仍可工作。
- 交付 `asset-manifest.md`：记录文件、用途、规格、渲染器映射、提示词摘要和验收结论。模板见 [references/manifest-template.md](references/manifest-template.md)。

## 动画素材（按需交付）

仅当用户的素材清单明确包含动画或状态切换时，才将其作为独立资产任务。定义触发时机、持续时间、帧数、帧布局、锚点、显示层级和回退，并在清单中标注状态与文件的映射。

涉及文字或数字时，优先生成无文字的主题化动画底框与特效，再由项目的 Canvas/HTML 绘制实际文案，以保证正确、清晰且可本地化。
## 前端风格指导（可选交付）

仅当用户明确要求输出前端风格指导提示词时，才额外交付 `frontend-style-prompt.md`。即使简报包含前端技术栈或主题信息，未提出该要求时也不输出此文件。

`frontend-style-prompt.md` 必须是一段可直接交给前端实现 Agent 的完整提示词，且必须包含：

- 视觉锚点、禁止元素和可实施的 CSS 颜色令牌；
- 标题、正文、弱文本、数字和快捷键的字体层级与前景/背景对比度；
- 适用于目标项目的信息层级、界面结构与交互状态；
- 用户指定动效的形状、时长、节奏及减少动态偏好；
- 资产文件到前端位置的映射，以及加载失败的几何/CSS 回退。

使用 [references/frontend-style-prompt-template.md](references/frontend-style-prompt-template.md) 作为结构。提示词必须说明应修改的前端文件、主题值、视觉令牌、组件规则和验收方式；浅色与深色主题都要单独验证正文、辅助文字和快捷键可读性。
## 使用示例

> 为俯视角机甲竞技小游戏制作可接入素材包：主题为“冰原采矿站”，低饱和冰蓝、铁锈橙和乳白警示色，正俯视、硬边金属轮廓、左上方冷光。输出 PNG 到 `client/assets/arctic-station/`。需要机甲（64×64，红/蓝两个颜色变体）、地面与障碍图块（32×32、可四边拼接）、能量弹（16×16）、命中特效（4 帧横向精灵表）。所有叠层素材带 Alpha、无文字无水印、单文件小于 50 KB；加载失败时保留现有几何绘制回退。另请输出一份 `frontend-style-prompt.md`，供前端实现与这套素材一致的界面主题。

应先交付素材简报：列出资产、尺寸、命名、透明度、优先级和共享风格锚点；以机甲、障碍和命中特效作为样本确认风格后再批量生成。最终交付资产文件、`asset-manifest.md` 与（因用户明确要求而生成的）`frontend-style-prompt.md`。前端提示词应引用实际资产目录，给出颜色令牌、字体层级、文字对比度、界面结构、用户指定动效和回退规则；不要虚构未生成的资产。
