# 前端风格实施提示词模板

交付时将下列内容替换为具体项目和主题，输出为 `frontend-style-prompt.md`：

```text
请为 <项目名> 实现与 <主题名> 美术素材匹配的前端视觉风格。前端技术栈为 <技术栈>；只修改 <允许修改的目录/文件>，不改变游戏规则或网络协议。

【风格锚点】
- 关键词：
- 材质、轮廓、光源、禁止元素：

【素材与主题映射】
- 主题值：<theme-key>；素材目录：<assets-path>。
- 已有素材：<文件及用途>。
- 加载失败回退：<几何/CSS 回退>。

【设计令牌】
- 背景/面板/边框/正文/弱文本/主强调/危险：<颜色令牌>。
- 字体：标题、正文、数字、快捷键分别使用 <规则>。
- 对比度：在实际背景上，正文、辅助文字、快捷键、禁用态必须清晰可读；浅色主题不能沿用暗色主题弱文本。

【布局与组件】
- 页面结构：
- 面板、按钮、输入、房间号、HUD、血量、战报：默认、悬停、焦点、禁用、淘汰状态。
- 用户指定的动效：使用 <动画素材文件>；若包含文字/数字，说明由 Canvas 或 HTML 绘制还是位图提供；说明帧切片、锚点、时长与减少动态偏好。

【验收】
- 主题切换后所有文字和快捷键均有足够可读性。
- 素材路径、尺寸、精灵表切片和回退正确。
- 桌面与移动端布局可用；不引入外部依赖或改动服务端逻辑。
```
